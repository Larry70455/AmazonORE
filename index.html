Saved Forms

How saving works

This checklist saves to a shared cloud database, so it works from any browser or device — open it on your phone, then pick it back up on a computer, and it's there.

Your entries autosave in the background as you type or check boxes, and the Save button gives you an explicit confirmation on demand. Every checklist you start becomes its own entry under Saved Forms, visible to anyone who opens this page — so multiple people can each be filling out their own checklist at the same time without overwriting each other.

The ☁ line under the toolbar tells you what's happening: saving, saved to the cloud, or an error if something's wrong (most often, the Firestore security rules need to be added in the Firebase console).

For a copy you can keep or send elsewhere, use PDF next to a saved form (or Print for the current form) to export an actual PDF.
